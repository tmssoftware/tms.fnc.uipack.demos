# TMS FNC UI Pack - Mobile Field Service

Phone app for service technicians: switch the device width, open a job, search parts; 44 px rows, columns that hide.

The Mobile preset of Quick setup applied in code (44 px rows, touch scrolling, finger-sized margins, single-row selection), Columns[].HidePriority (columns leave a narrow grid one by one) and MasterDetail.DrillDown.Width (a job opens in place of the list on a phone) on a data grid, a tree view with a breadcrumb and a list box with a search edit, in a device frame of a phone, a tablet or the full width. On Android and iOS the app fills the screen.
