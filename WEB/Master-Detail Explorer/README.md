# TMS FNC UI Pack - Master-Detail Explorer

Customers with their orders and order lines from linked datasets: grid, form, tabs or cards detail, under the row, in a detail view (TTMSFNCDetailView) next to the grid or as a drill-down with a breadcrumb; a template per level (order lines as cards), the detail tool bar with search and Add, a peek preview, summaries, sticky master, editing; a page without a database (OnGetDetailData) and a tree grid with aggregates and children loaded on expand.
