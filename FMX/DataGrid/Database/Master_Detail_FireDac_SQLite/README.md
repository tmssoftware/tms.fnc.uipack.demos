# TMS FNC DataGrid - Master-Detail with the database adapter (FireDAC, SQLite)

The master-detail of the TTMSFNCDataGridDatabaseAdapter: a detail grid bound through the adapter DetailControl of an orders table in the SQLite database fddemo.sdb. Kept as the adapter demo; the 8.0 way, DataGrid.DataSource with MasterSource and the templates per placement, is in the Master-Detail Explorer demo (`FMX/Master-Detail Explorer`).
